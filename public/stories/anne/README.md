# Anne Story Assets

Generated story illustrations go in `images/`:

```text
public/stories/anne/images/<story-id>-page-<page-number>.webp
```

Future read-aloud clips can go in `audio/`:

```text
public/stories/anne/audio/<story-id>-page-<page-number>.mp3
```

Run `npm run generate:story-images:dry` before generating to preview prompts and paths.
